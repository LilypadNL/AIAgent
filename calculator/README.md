# Calculator

A simple command-line calculator application written in Python.

## Usage

To run the calculator, execute the `main.py` file with your desired expression as an argument:

```bash
python main.py "<expression>"
```

### Examples

```bash
python main.py "3 + 5"
# Expected Output: {"expression": "3 + 5", "result": 8}

python main.py "10 / 2 - 1"
# Expected Output: {"expression": "10 / 2 - 1", "result": 4}

python main.py "2 + 3 * 4"
# Expected Output: {"expression": "2 + 3 * 4", "result": 14}
```
